# BioTest PWA

Bu papka Mac kerak bo'lmasdan iPhone Home Screen'dan appdek ochiladigan web app uchun tayyorlandi.

## iPhone'ga qo'yish

1. `BioTest-PWA` papkasini HTTPS hostingga yuklang: Netlify, Vercel, GitHub Pages yoki oddiy hosting.
2. iPhone'da linkni Safari orqali oching.
3. Share tugmasi -> Add to Home Screen -> Add.
4. Home Screen'dagi BioTest ikonkasini bosing.

## Muhim

- iPhone'da service worker va offline cache normal ishlashi uchun sayt HTTPS orqali ochilishi kerak.
- Telegram/Chrome ichidan emas, aynan Safari ichidan Add to Home Screen qiling.
- Birinchi marta ochilgandan keyin asosiy fayllar cache qilinadi.
