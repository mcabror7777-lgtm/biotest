**Ochish:** https://mcabror7777-lgtm.github.io/biotest/turk-tili/

- Test: Turkcha → O'zbekcha va O'zbekcha → Turkcha (4 variant)
- Yozib javob (turkcha harflar tugmasi, ğ/ş/ç'siz yozilsa ham qabul qilinadi)
- Kartochkalar (bosib ag'darish, o'ngga/chapga surish)
- 60 soniya chellenj, ball, seriya, rekordlar, kunlik maqsad
- Xatolar ustida ishlash: xato so'zlar 2 marta to'g'ri topilguncha takrorlanadi
- Turkcha talaffuz (qurilma ovozi), yorug'/qorong'i rejim, telefon va kompyuterga moslashadi
- Natijalar shu qurilmada saqlanadi; internet bo'lmasa ham ochiladi
